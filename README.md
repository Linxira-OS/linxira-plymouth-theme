# Linxira OS Plymouth Theme

Jimmac's spinner theme using the ACPI BGRT graphics as background with Linxira OS branding

*Based on [cachyos-plymouth-theme](https://github.com/CachyOS/cachyos-plymouth-theme) (GPL-3.0).*

**Build dependency**: required by [linxira-iso-direct](https://github.com/Linxira-OS/linxira-iso-direct) — pass this checkout to `build-direct-iso.sh --plymouth-theme-directory <path>/src`.
